# PLASU Online Alert Security System

A real-time campus security alert system with GPS tracking. Students can send instant emergency alerts with their location to security personnel.

## 🚀 Features
- One-tap SOS button with GPS location
- Real-time alerts to security dashboard
- Multiple alert types (Security, Fire, Medical)
- Live tracking of active emergencies
